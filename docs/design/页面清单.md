# 页面清单与布局对照

> 已有＝当前代码有基础；优化＝已有并需重组/扩展；新增＝目标设计，未接线上服务。

## 01. 领养与建房 · 优化

- 当前：小窝页的领养弹窗；个人资料未设置时先前往「我」。
- 布局：个人头像 → 宠物预览 → 昵称/虚拟出生城市 → 创建房间
- 交互入口：编辑我的资料；选外观与名字；创建房间并邀请
- 规则：正式进度从对方接受开始。；新增：创建前可玩短试玩，不发成长奖励。；可选路线：真实单养→共养，尚不替换默认规则。

## 02. 邀请与轻角色 · 优化

- 当前：已有复制、续期、受邀预览、接受和失效反馈。
- 布局：宠物邀请封面 → 房主昵称 → 邀请有效期 → 轻角色 → 接受
- 交互入口：复制邀请链接；选择邀请称号；预览受邀页
- 规则：喂饭官 / 造型师 / 探险搭子只是称号，任何成员可完成全部照料。；自己不能接受自己的邀请；过期支持房主重发。；预览器中的受邀页是设计场景，不是身份切换。

## 03. 受邀者接受 · 优化

- 当前：链接读取房主和宠物；先设置资料，再接受后原子成立。
- 布局：邀请来源 → 自己的资料摘要 → 可选称号 → 明确接受
- 交互入口：设置自己的资料；接受邀请，成立房间；查看失效邀请效果
- 规则：仅展示房主公开昵称和头像，不展示其私人简介。；接受成功 → 小窝，双方开始D1。；已在其他房间、被抢先加入、断网均需明确反馈。

## 04. 小窝首页 · 优化

- 当前：宠物、XP/活力/羁绊/品质、照料、地图、估值、剧情与日历入口。
- 布局：今日状态 → 宠物舞台 → 喂养/抚摸 → 待回应事件 → 次要入口
- 交互入口：免费喂养；摸摸团子；回应伙伴接力；教它一个习惯；查看成长报告；养宠日历；宠物估值；成长奖励；99天剧情
- 规则：新增接力卡优先于大面积功能宫格，首页只突出一件待办。；保持XP、活力、品质与羁绊区分；不因少聊天降羁绊。；免费照顾足以健康成长；粮食数值暂不照搬文档。

## 05. 情侣地图 · 优化

- 当前：虚拟地图可拖缩放，6地点、寻宠、回忆点；约会在互动页。
- 布局：顶部任务气泡 → 城市地图 → 地点抽屉 → 回忆/明信片
- 交互入口：开始双人寻宠；抽一张约会任务；寄旅行明信片；打开宠物小屋
- 规则：地图标记是虚拟地点，不读GPS。；新增旅行明信片入口；点区域显示锁定/开放原因。；寻宠线索按当前本人权限返回，不能切为伙伴。

## 06. 心动互动 · 优化

- 当前：6个标签：信使、需要、默契、约会、未来信、修复。
- 布局：待回应置顶 → 共同习惯/接力 → 情感互动 → 异步记录
- 交互入口：谁教它的；共同接力事件；宠物信使；今天需要什么；默契挑战；约会盲盒；未来情书；情绪修复站
- 规则：新增玩法并入原互动中心，避免扩张底部导航。；未回应显示等待，不展示对方未公开答案。

## 07. 团子商店 · 优化

- 当前：分类、详情、余额检查、模拟购买、背包、换装；目前房间共享物品。
- 布局：余额与模拟标识 → 分类 → 商品网格 → 详情确认 → 背包
- 交互入口：试穿蝴蝶结；模拟购买 · 100爱心币；查看我的衣橱；共同布置小屋
- 规则：新增：衣橱归购买者，宠物共享展示；现有共享背包需要迁移规则。；支付仍模拟；真实会员和支付需正式接入。；付费不提升现金奖励资格。

## 08. 我 / 个人中心 · 优化

- 当前：目前是自己资料表单、房间、换装、小屋和更多入口。
- 布局：本人资料卡 → 房间 → 衣橱 → 成长档案 → 设置
- 交互入口：编辑我的资料；我的双人房间；我的衣橱；养宠日历；成长奖励；分享工作台；暂停与退出；体验设置与数据
- 规则：只编辑自己；伙伴昵称和头像在房间页呈现。；把更多功能聚合为清晰分类，减少页面间找入口。；当前浏览器会话无账号恢复，Jagat正式身份仍待接入。

## 09. 双人房间 · 优化

- 当前：成员公开信息、状态、邀请与确认解除；解除清除私人信与未揭晓投票。
- 布局：房间状态 → 两位成员 → 宠物与分工称号 → 管理
- 交互入口：查看邀请；去共同养宠；暂停或退出
- 规则：新增暂停/只读托管，不能把现有解除当作保留纪念。；退出后撤销共享写权限；未送达信件与选票按规则处理。

## 10. 谁教它的 · 新增

- 当前：当前只有性格累计与进化，没有双人习惯组合。
- 布局：我的习惯选择 → 等待对方 → 双方组合结果 → 日记/分享
- 交互入口：教它：早睡；教它：勇敢探索；预览双方完成结果；做成习惯卡
- 规则：结果示例：你教早睡，伙伴教夜宵 → 抱着饭碗睡觉。；此处预览伙伴结果仅用于评审，正式页不能替伙伴提交。；有限模板组合；不读取私聊，不做人格诊断。

## 11. 双人接力事件 · 新增

- 当前：现有异步挑战，但没有48小时共同事件窗口。
- 布局：伙伴留下的物件 → 我的回应选择 → 短动画 → 共同回忆
- 交互入口：接力：挑一颗星星；换个轻任务；查看共同回忆
- 规则：示例：伙伴搭好帐篷，你挑今晚的星星。；窗口到期只结束本次事件，不扣永久成长与羁绊。；48小时/每周上限为待测参数，需服务器去重。

## 12. 领养外观 / 捏脸 · 新增

- 当前：已有初始颜色和服装，没有耳朵、眼型与花纹编辑。
- 布局：宠物大预览 → 耳朵/眼型/颜色/花纹 → 共同确认
- 交互入口：换一个配色；切换耳朵；预览保存与共同确认
- 规则：有限原创SVG部件组合，不依赖AI生图。；新外观需双方同意时显示草稿/待确认/生效，不单边覆盖。；免费次数与会员权益暂不固定收费规则。

## 13. 成长档案 / 反差照 · 优化

- 当前：已有性格进化和日历事件，没有领养快照与前后对比卡。
- 布局：初生 vs 现在 → 习惯 → 进化节点 → 地图故事 → 海报
- 交互入口：看D21对比；看D49对比；看D77对比；导出成长对比卡；模拟估值明细
- 规则：新增保存阶段外观快照，换装后不篡改历史。；D21/D49/D77沿用既有进化节点；D30另保留成长报告。

## 14. 养宠日历 · 优化

- 当前：月切换、日期详情、XP、品质与估值变化、日记。
- 布局：本月概览 → 日历格 → 当日照料/伙伴参与 → 日记
- 交互入口：选择D21纪念日；查看宽限徽章；查看日记与回忆
- 规则：新增每周宽限陪伴徽章；自然日与连续互动分开。；缺席不清空99天进度，不删除历史与外观。；徽章参数需试验，非现有奖励计算。
