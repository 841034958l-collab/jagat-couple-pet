# 当前共享版边界

已实现Node HTTP API，支持PostgreSQL共享数据库与本地SQLite。每个浏览器获得独立、随机HttpOnly Cookie会话，服务器保存会话令牌哈希，根据成员关系决定房主或受邀人身份。客户端没有切换角色按钮，也不能在请求中指定自己是另一位。

## 已运行的能力

- 个人资料仅本人可编辑。伙伴仅看到共同房间需要的公开昵称、头像，不得到对方个人简介或个人城市。
- 一人创建邀请，另一人明确接受后原子绑定并启动周期。拒绝过期、撤销、自己接受自己、已有房间重复绑定、多人并发抢占。
- 共同宠物、钱包、背包、装扮、小屋、成长事件与任务存储在服务端。前台约2秒轮询同步；过时的轮询结果不覆盖新的修改。
- 命令角色由服务器成员身份确定，不采纳客户端role或roomId。成长规则与去重在服务器执行。
- 未到期未来信不返回正文；未揭晓选票只返回提交状态。数据库以事务写入，重复接受不会再次启动周期。
- 持久化会话/资料/房间在服务重启后恢复，PostgreSQL模式不依赖应用磁盘；SQLite模式要求路径在持久化盘。
- `DEMO_MODE=false`时，服务端按绑定后的每24小时推进1个自然日，上限99天；禁止客户端改日、模拟审核和广告命令。

## 仍需正式接入

- **正式账号**：当前是浏览器匿名会话，不是手机号/密码/Jagat登录。会话有效180天，无找回、跨设备登录、登出/账号合并管理；Cookie丢失会失去当前身份。
- **运维与规模**：免费部署使用Supabase PostgreSQL，当前使用小规模Demo的全局事务应用锁；SQLite备选仅单实例。上线需制定备份、恢复、容量/频控、监控、会话过期清理、灾备、访问审计与数据删除流程。大规模并发需细化房间行锁、唯一约束和全局频控；现有应用锁虽可跨连接池协调，但不代表通过了规模压测。
- **即时同步**：当前轮询，无WebSocket推送。页面在后台时暂停轮询，回到前台恢复。
- **财务能力**：商品、星星币、基金审核、广告仍模拟。没有真实支付、奖励额度、财务转账或真实广告SDK，不提供现金收购承诺。
- **Jagat能力**：仍需JagatBridge身份签名验证、地图、分享回调、官方账号权限，以及iOS/Android/WebView真机测试。
- **隐私治理**：解除绑定清除该房间私人信件、偏好与未揭晓投票，保留成长归档；目前没有自助彻底删除服务端个人账号和归档的入口，正式收集信息前须补齐政策与删除操作。

旧版LocalStorage存档不导入服务器，以免把一个人可扮演两角的旧演示数据误绑定到真实身份。原始文件保留，当前前端不再读取。

部署用render.yaml和Dockerfile已提供，但文件存在不代表已创建外部服务。GitHub Pages不能执行Node/SQLite，因此CI改为验证构建，公开共享站点需单独完成Render等托管服务创建。

## 免费部署与数据库权限

render.yaml选择Free Web服务、不带付费磁盘，数据库使用用户自己的Supabase Free项目。DATABASE_URL/DATABASE_PASSWORD仅由服务端读取，前端不会获得数据库凭据。表创建在私有jagat_private schema，不在默认Data API暴露范围，PUBLIC无schema/table权限。

远程连接使用TLS且rejectUnauthorized=true；独立密码字段自动URI编码；可配置官方CA。启动错误不输出连接串。默认连接池最多2条连接，事务完成后响应才发送，跨实例应用锁防止覆盖写入。

免费平台可能休眠、限额或暂停。没有对用户实际Supabase项目进行带凭据验收，也未创建Render服务。真实部署与恢复、备份及数据删除政策仍需用户配置和验收。

## V4增量规则

随机任务从宠物ID和服务端养宠日稳定生成，任务领奖需当日存在对应照顾事件，按任务ID+日去重。照护分依据追加事件回算，不修改旧XP或将旧模拟金额转成债权。无真实支付/基金/公益转付，care_plan_activate仅允许演示模式，房间只有一份模拟权益。自然时间在所有模式推进，演示房主可独立跳日前瞻；跳日不是真实活动资格。

Three.js仅使用本地程序几何和材质。WebGL失效显示降级角色；页面后台暂停动画并释放卸载资源。尚未完成iOS/Android/WebView真机、规模压测与官方Jagat美术验收。首次故事观看标志仅当前浏览器本地，不是服务端跨设备账号状态。

## V4.1视觉与故事

参考用户提供的Jagat原生截图，新增统一深色主题与荧光渐变。程序几何宠物使用本地RoomEnvironment生成反射、MeshPhysicalMaterial虹彩与高光；未取得或复用官方贴纸资产。环境贴图64px、动画限制30fps且离屏停止，卸载后释放环境与GPU资源。真实iOS/Android WebView性能仍需验收，不能从软件渲染测试推导真机帧率。

故事入口改为完整的故事哈希页（#shelter），页内可播放/重播五幕开场，世界观/章节/玩法/权益/公益均为同页独立区域。首次自动播放标记仍为浏览器本地jagat-care-story-v4，已有观看标记不重复强弹。页面不对应已成立的真实公益机构，模拟支付与奖励规则不变。
