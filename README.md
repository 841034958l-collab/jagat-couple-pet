# Jagat「99天养宠计划」V3.0

> 我们一起养了它99天。最后一天，你会留下它，还是把它交给 Jagat？

可运行的移动端 H5 Demo。复用原有 React + TypeScript + Vite，使用 Lucide、原创 SVG 宠物、CSS 插画和虚拟城市地图。无外部图片或远程字体依赖。采用 hash 导航，兼容 GitHub Pages 子路径；状态通过独立 GameAPI 管理，不额外引入状态库、路由框架或 CSS 框架。

**当前是本机 Demo，不是正式联机服务。**所有金额、购买、广告、奖励审核都明确模拟；没有真实支付、现金转账、GPS、登录或外部自动发布。双方角色共享本机存档，角色切换不是身份认证，不能用来保存敏感私人信息。

## 运行

需要 Node.js 20.19+ / 22.12+，推荐 Node.js 24。

```bash
cd /workspace/jagat-couple-pet
npm ci
npm run dev -- --port 5173
```

本机浏览器打开 `http://localhost:5173`。云端需使用平台提供的端口转发访问5173；本仓库不假设当前平台具备预览功能。手机与电脑同网络时可使用电脑的局域网 IP 加5173端口。

```bash
npm test                # Vitest 业务 / API / React组件测试
npm run build           # TypeScript检查 + Vite生产构建
```

```bash
npm run preview -- --port 4173
```

## Demo 完整体验路线

### 1. 双人领养

1. 首页点击「开始领养」，使用顶部 A 角色创建房间，设置昵称、虚拟出生城市与初始颜色。
2. 顶部切换 B，点击「我是 B，接受邀请」。
3. 切换 A，点击「我是 A，确认共同领养」。此刻启动 D1。
4. 「双人房间」可生成24小时有效邀请链接、查看绑定状态和解除绑定。Demo 链接仅同浏览器存档可接受，不能跨设备同步；复制成功不代表真实邀请激活。

### 2. 日常照顾、成长、品质

- 首页免费基础粮每天2次，每次+5 XP；摸摸、故事、休息、整理小屋各每天1次。
- 等级使用 `xpThresholds` 配置；不因未登录下降。活力与羁绊范围0–100，宠物不会死亡。
- 五维品质：营养25%、情绪25%、探索20%、共同责任20%、环境10%。每维双方合计每日最多+10，单维累计上限100，当前99天周期内累计、不衰减。
- 评分来源、每项贡献和追加式更新记录见「宠物估值」。同日回跳不会清除任务上限。
- 免费粮、免费互动、探索、寻宠和整理足以达到五维满分；自动化测试覆盖十个照顾日的免费满分路线。消费、广告不会直接增加品质或现金资格。

### 3. 估值与日历

手机底栏「更多」打开 Demo 面板，从快捷入口进入「宠物估值」「养宠日历」等页面；桌面可直接用侧栏导航。

- 估值以整数分计算：`min(19900, round(1990 + 8000×D/99 + 9900×Q/100))`。
- D1/Q0 为¥20.71，D99/Q100 为¥198.90；¥199为封顶值，公式本身不会恰好到¥199。
- 展示昨日有记录时的对比、实际历史曲线、五维贡献、解释记录、收藏等级与D99假设推演。
- 日历有4个周期月视图（30/30/30/9天）、日期详情、A/B参与、喂食、XP/等级/活力/品质/估值变化、日记和奖励记录。
- 没有互动的日期不伪造历史；连续活跃与养宠自然日独立。

所有估值均显示：**游戏内模拟估值，不代表 Jagat 真实现金收购承诺。**

### 4. 地图与小屋

- 六区域：爱心小屋、心动公园、迷路街区、约会咖啡馆、回忆车站（D10）、星光灯塔（D90）。
- 鼠标/单指拖动，滚轮/双指缩放，加减按钮与复位，地点点击、宠物位置动画、回忆标记。
- 「开启地图寻宠」后，各角色分别打开线索。两位都看过才可查找；错误有反馈，成功每日+20XP并生成吐槽日记。
- 寻宠进行中需先完成当前回合再跳剧情日期，避免回退后目标区域锁定。
- 地图快捷入口或「更多→布置小屋」：切换免费床/碗/玩具/家具、墙纸和地板；选家具后点击「移动选中家具」，再点小屋位置；保存后A/B共享。
- 付费模拟主题/家具可从背包使用；整理小屋任务提供环境加分，与家具价格无关。

### 5. 情感互动与异步小游戏

「心动互动」有六个选项卡：

- 宠物信使：模板或自填心意，对方回复后每日首次+5XP。信件支持删除。
- 今天需要什么：双方分别选择，团子给轻量建议；和事佬支持双方生活提案与折中建议。
- 默契小游戏：晚餐、心情、约会、装扮、口令。各自提交选择并猜对方，双方提交前不显示另一位答案。每日首次双人任务+10XP。
- 约会提案：抽取任务，双方分别确认完成，生成地图约会报告，每日首次+30XP。完成「约会」偏好挑战后会将双方偏好加入任务描述。
- 未来情书：D30/60/90解锁。未到期接收者API投影不返回正文；发送者可读自己的草稿并撤回未送达信件。
- 情绪修复：故事、摸摸、休息、整理；没有心理诊断或关系好坏评分。

五种性格由互动选择权重形成，在D21/49/77变换进化表现：暖阳、冒险、慢热、贴贴、自在，没有好坏等级。

### 6. 商城、背包与模拟奖励

- 商店有8类商品、详情、确认、余额检查、重复购买限制。初始300爱心币、18枚模拟星星币；无充值入口。
- 背包可佩戴帽子/蝴蝶结/服装、使用家具/主题、喂食特色粮和零食，实际改变宠物或小屋外观。
- 基础粮永久免费。特色粮与零食和基础粮共享每日2次喂养上限；价格不影响营养分。
- 「更多→Demo面板」快速跳到D10/30/60/90，进入「成长奖励」分别领取礼包，最多一次，随后可提交一次模拟基金申请。
- 申请记录支持模拟审核通过/不通过，始终标注未真实到账。UGC申请独立，只接收用户主动填写的HTTPS链接，不验证外部发帖、不自动打开链接、不承诺奖励或名额。
- Demo广告仅在Demo面板主动开启，播放模拟等待后赠送日记背景，不增加XP/品质/估值贡献/现金资格。关键私密节点无广告。

### 7. 快速体验 D1–D99 与三种结局

1. 完成共同领养后，手机「更多」进入 Demo 面板。
2. 使用日期输入或D1/7/10/21/30/35/49/60/77/90/98/99快捷按钮切换。只改变演示剧情日，不补造日常事件。
3. 「99天故事」翻开已解锁章节；进化日可以查看宠物性格，奖励日去领奖。
4. D99进入「毕业选择」，查看完整形象、等级、五维入口、XP曲线、估值、地图冒险、共同回忆和毕业信。
5. A独立选择并密封，切换B。双方均看到「留下宠物 / 交给Jagat」相同选项；只显示提交状态，不提前返回答案。
6. 两人留下→「永远的家」；两人交给Jagat→「星球毕业」；不同→「再商量一次」，宠物留在地图，可重开一轮。
7. 一致结局确认后获得纪念形态，再到「成长奖励」领取D99纪念册与申请最高模拟¥99基金。
8. 要体验另外两种结局，可在Demo面板重置后重新绑定并跳D99。重置会清除V3本机数据，操作前有确认。

### 8. 六种海报

「分享纪念」支持出生证明、出逃通缉令、默契报告、性格进化卡、30天成长报告、99天秘密结局卡。默契/进化/成长/终局卡有对应解锁条件。

- 3:4（900×1200）、9:16（900×1600）、微信1:1（900×900）PNG。
- 可隐藏宠物昵称、出生城市，主动选择是否展示A/B角色信息。
- 结局海报必须在本轮揭晓后两人分别同意。没有原始单人秘密选票或信件正文。
- Canvas生成后触发下载，并展示图片供手机长按保存。错误会提示并允许重试，失败不会记录成成功生成。
- 只记录生成和下载按钮点击，不伪造外部分享成功。

## 自动化测试

```bash
npm test
npm run build

# 第一次在自己的电脑上运行E2E，需要安装浏览器
npx playwright install chromium
npm run test:e2e

# 本云环境有系统 Chromium，可避免额外下载
PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH=/usr/bin/chromium npm run test:e2e
```

Playwright自动启动5174端口的独立测试开发服务器，使用独立浏览器上下文；不依赖5173进程或已有存档。测试实际覆盖的结果以运行日志为准。

- 业务：估值边界、免费满分路线、XP/每日去重、邀请过期、绑定、A/B异步提交、私密投影、三种结局、反复投票、分享同意、余额不足、重复购买/奖励申请、解绑、模拟广告。
- API：刷新恢复、存档损坏、保存失败、串行命令幂等、重置。
- 组件：弹窗关闭与Escape、估值提示、进度显示。
- 浏览器：完整领养→照顾→信件→地图寻宠→商城装扮→小屋保存→日历→PNG→奖励申请；三种终局；图片失败与重置；地图拖动缩放复位、需要表达、异步默契、约会报告、模拟广告；375/390/430px和桌面布局。

实际iOS Safari、Android真机、WebView兼容性仍需真机测试；当前自动化使用Chromium。未声称经过真实支付、广告、财务审核或多设备验证。

## 项目结构

```text
src/
  domain/
    models.ts        # 完整实体、ID、状态、ISO时间、金额分
    config.ts        # 任务/商品/剧情/奖励/XP/品质权重
    engine.ts        # 命令验证、去重、追加成长事件、角色投影
    story.ts         # StoryEngine、服务端自然日计算工具
    *.test.ts
  services/
    adapters.ts      # 正式API、地图、支付、奖励、广告、WebView接口
    mock.ts          # 本机Mock API、串行命令、持久化与恢复
    rewards.ts       # 独立MockRewardService与RewardPolicy
    poster.ts        # 本地Canvas海报生成与下载
    mock.test.ts
  components/        # 原创恋爱团子、地图插画、成长图表、UI
  pages/             # 首页、双人房间、地图、小屋、互动、估值、日历、
                     # 商城、奖励、剧情、毕业、分享、Demo数据面板
  store.tsx          # React Context，只通过GameAPI操作业务状态
  main.tsx           # 导航与启动
  v3.css             # 响应式粉/紫/薄荷UI、动画、减少动态偏好
 e2e/game.spec.ts     # 浏览器回归
 .github/workflows/deploy.yml
```

本机持久化键为 `jagat-99-v3`。旧版 `jagat-v1` 未自动迁移或删除，以免把旧玩法数据误算为99天奖励资格。V3重置只清除V3数据。数据不会上传到远程；不默认请求定位、读取聊天或照片。

## 正式 Jagat App 接入边界

当前可替换边界见 [docs/production.md](docs/production.md)。`HttpGameAPI`提供HTTPS请求入口，但**没有已完成的正式后端**，不得直接以本地角色、日期、钱包、品质、投票或申请作为正式凭证。

正式发布前需接入身份会话、情侣权限、时间与任务校验、并发/幂等存储、服务端投票隔离与揭晓、邀请有效期和权限、支付回调、奖励政策与名额、财务审核、隐私删除，以及真机测试。生产端不得暴露Demo跳日、角色切换或模拟审核能力。
